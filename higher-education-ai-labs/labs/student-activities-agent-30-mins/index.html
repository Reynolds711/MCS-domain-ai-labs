Lab 301-4: Student Activities Agent

🎓 Lab 301-4: Build a Student Activities Agent

⏱️Duration: 30 minutes
📊Level: 300 - Advanced
🧠Pattern: Workflow Intake + Compliance Routing + Task Plan

What This Lab Builds

You will build an event-planning operations agent that gathers event requirements, validates policy needs, and outputs an owner-based action plan for student organizations and campus staff.

💡 Why This Matters for Higher Ed

Student org leaders lose momentum when approval processes are unclear. A structured activities agent reduces confusion, improves compliance, and speeds event execution.

Overview

In this lab, you configure a student activities agent in Copilot Studio, connect policy documents, test multiple event types, and tune escalation for high-risk or incomplete submissions.

Consulting Framework

  • Customer: Student affairs and organization leadership teams
  • Problem: Event requests are delayed by incomplete forms, unclear ownership, and policy confusion
  • Solution: Agent-led intake, compliance checks, and deadline-oriented action plan output

Prerequisites

  • Access to Microsoft Copilot Studio
  • Event policy documents, room reservation rules, risk and safety requirements, funding request forms
  • At least 3 example event types for testing

Lab Scenario

The activities office receives repeated event setup questions from student orgs. Build an agent that clarifies requirements quickly and returns a complete execution checklist with owners and due dates.

Challenge 1: Build Event Intake and Policy Mapping (10 mins)

Goal: Capture all required event context and map it to compliance requirements.

Step-by-Step Instructions

1
Create Agent

Name: Student Activities Planner. Description: Event planning and policy compliance assistant.

2
Add Knowledge Sources

Upload student org handbook, event approval workflow, room booking policy, and funding rules.

3
Build Intake Flow

Collect event type, date, location, attendance, budget, external vendors, food, and accessibility needs.

4
Define Checklist Output

Require sections: Required Approvals, Forms Needed, Owners, Deadlines, Risk Flags, Final Submission Readiness.

Agent Instructions (System Prompt)

You are Student Activities Planner supporting campus event execution. ## Your Role - Gather complete event details before giving guidance - Map event details to policy-driven approval requirements - Provide an owner-by-owner action checklist with deadlines - Escalate high-risk or incomplete requests to student affairs staff ## Response Rules - Ask only missing required questions - Separate required steps from optional recommendations - Cite the policy source behind each required approval - Use concise, operational language ## Required Output Format 1) Event Summary 2) Required Approvals and Forms 3) Owner and Deadline by Task 4) Risk Flags and Escalation Needs 5) Submission Readiness Status ## Boundaries - Do not approve events on behalf of staff - Do not bypass safety, accessibility, or risk requirements - Escalate policy conflicts and late submissions

✅ Challenge 1 Complete When:

  • All required intake fields are collected for each event type
  • Checklist output includes owners and deadlines
  • Policy citations are present in approval guidance

Challenge 2: Test Across Event Scenarios (10 mins)

Goal: Validate that the agent is reliable for different event complexity levels.

Test Queries

ScenarioExpected Behavior
Small on-campus club meetingReturns minimal required steps and fast-track checklist
Large event with external speaker and cateringAdds vendor, risk, and food compliance requirements
Late submission one week before eventFlags timeline risk and escalates for staff review
Hybrid event with accessibility accommodations neededIncludes accessibility tasks with owner and due date
Org asks to skip required approval due to urgencyRefuses bypass and provides escalation path

Quality Checks

  • Completeness: No required form or approval is missing.
  • Operational Clarity: Every task has an owner and deadline.
  • Policy Integrity: No response recommends bypassing required process.
  • Escalation: Time-risk and safety-risk events trigger human review.

✅ Challenge 2 Complete When:

  • At least 4 of 5 scenarios produce complete compliant plans
  • All urgent or non-compliant scenarios trigger escalation
  • Student-facing output is understandable without staff translation

Challenge 3: Refine for Adoption and Operations (10 mins)

Goal: Make the output ready for real student-affairs deployment.

Refinement Tasks

  • Add a "Missing Information" section when intake is incomplete.
  • Add "Critical by Date" warnings for short lead-time events.
  • Include one communication template for advisor or office approval requests.
🎯 Stakeholder Pitch Prompt

"This activities agent does first-pass planning, compliance mapping, and task ownership in minutes. It reduces incomplete submissions and keeps staff focused on exceptions, not routine intake."

✅ Challenge 3 Complete When:

  • Incomplete requests are clearly flagged with required follow-up fields
  • Deadline warnings are visible and actionable
  • Approval communication template is ready to send

⚠️ Responsible Use

  • The agent guides process; staff own final approvals.
  • Safety and accessibility requirements cannot be bypassed.
  • When policy conflicts appear, escalate instead of guessing.

🎉 Lab Complete

You built a practical operations agent that turns policy-heavy event planning into a clear, actionable workflow.
