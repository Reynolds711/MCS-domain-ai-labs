Student Activities Agent (30 mins)

🏗️ Build a Student Activities Agent

⏱️Duration: 30 minutes
🧭Scenario: Event Planning and Approval Workflow
📂Data: Event Policy + Room Booking Rules + Student Org Handbook

Scenario

Student org leaders lose time navigating event policies and approval steps. Build an agent that gathers event details, validates requirements, and returns a checklist with owners and deadlines.

Challenge 1: Build Event Intake (10 mins)

  • Collect organization name, event type, audience size, date, and location preference.
  • Ask for budget status, external speakers, food, and safety considerations.
  • Confirm whether event is on-campus, virtual, or hybrid.

Challenge 2: Add Compliance and Approval Logic (10 mins)

  • Map intake details to required approvals and lead times.
  • Flag missing forms and policy conflicts before submission.
  • Escalate high-risk events for staff review.

Challenge 3: Generate Action Plan (10 mins)

  • Produce a checklist with due dates and owner by task.
  • Include room booking, marketing, accessibility, and risk-management steps.
  • Provide a communication template for advisor sign-off.

✅ Complete When

  • Agent captures all required event intake fields
  • Approval checklist matches policy across 3 event scenarios
  • Output provides a clear owner and deadline for each task

Deliverable

Submit 3 event scenarios with generated compliance checklist and final approval action plan.
