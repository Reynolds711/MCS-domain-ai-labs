Adaptive Tutor Agent (35 mins)

🏗️ Build an Adaptive Tutor Agent

⏱️Duration: 35 minutes
🧭Scenario: Guided Tutoring with Escalation
📂Data: Course Objectives + Practice Sets + Tutor Support Policy

Scenario

Students often need support outside tutoring-center hours. Build an agent that coaches through questions, diagnoses misconceptions, and escalates to a human tutor when progress stalls.

Challenge 1: Design Question-First Tutoring Flow (10 mins)

  • Start by asking what the student has already tried.
  • Use scaffolded hints from easier to deeper conceptual prompts.
  • Avoid direct final answers unless explicitly allowed by policy.

Challenge 2: Add Mastery Checks (10 mins)

  • After each hint cycle, ask one short check-for-understanding question.
  • Track confidence and error patterns during the conversation.
  • Adjust difficulty level based on demonstrated understanding.

Challenge 3: Build Escalation Logic (10 mins)

  • Escalate after repeated confusion or low-confidence responses.
  • Create a tutor handoff summary with misconceptions and attempts made.
  • Provide next available support options (office hours, tutoring center, peer tutor).

Challenge 4: Add Integrity Guardrails (5 mins)

  • Block requests for direct assignment completion.
  • Require coaching language that supports learning, not answer dumping.
  • Include a reminder to verify work with instructor guidance when appropriate.

✅ Complete When

  • Agent keeps to a question-first tutoring style
  • Mastery checks are present in all 3 test conversations
  • Escalation summary is actionable for human tutors

Deliverable

Submit 3 tutoring conversations that show beginner, intermediate, and escalation-required paths.
