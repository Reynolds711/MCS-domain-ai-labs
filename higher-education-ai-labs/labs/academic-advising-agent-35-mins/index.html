Academic Advising Agent (35 mins)

🏗️ Build an Academic Advising Agent

⏱️Duration: 35 minutes
🧭Scenario: Degree Planning + Advising Triage
📂Data: Degree Map + Course Catalog + Advising Policies

Scenario

Advisors spend too much time on repetitive degree-audit questions. Build an agent that captures student context, identifies requirement gaps, and proposes a next-term schedule that can be reviewed by an advisor.

Challenge 1: Build Multi-Turn Intake (10 mins)

  • Collect program, completed credits, transfer credits, and target graduation term.
  • Capture constraints: work schedule, modality preference, max course load.
  • Confirm student priorities before generating recommendations.

Challenge 2: Add Degree-Gap Logic (10 mins)

  • Map completed coursework to degree requirements.
  • Return clear "complete", "in progress", and "remaining" sections.
  • Flag unresolved transfer-credit ambiguity for human advisor review.

Challenge 3: Generate Next-Term Schedule (10 mins)

  • Recommend 3 to 5 courses with rationale tied to requirement completion.
  • Respect prerequisites and student time constraints.
  • Include a risk note when a recommendation may delay graduation.

Challenge 4: Build Handoff Summary (5 mins)

  • Output a one-page advising summary: goals, gaps, plan, and open questions.
  • Add escalation triggers for probation risk or failed prerequisite chain.
  • End with advisor approval step before final registration action.

✅ Complete When

  • Agent asks only required follow-up questions
  • Degree-gap summary is accurate across 3 test student profiles
  • Course recommendations align to prerequisites and constraints

Deliverable

Submit 3 advising simulations, each with intake transcript, degree-gap output, and final advisor handoff summary.
