Student Services Case Orchestration Agent (30 mins)

🏗️ Build a Student Services Case Orchestration Agent

⏱️Duration: 30 minutes
🧭Scenario: Cross-Functional Student Services
📂Data: Policy Docs + Institutional FAQs

Scenario

Student requests often span multiple offices. Build an agent that clarifies intent, collects missing context, and routes each case with a clean summary to the correct team.

Challenge 1: Design Multi-Turn Intake (10 mins)

  • Start with request category detection (advising, registrar, aid).
  • Ask follow-up questions only when critical fields are missing.
  • Confirm student objective before routing.

Challenge 2: Add Routing and Escalation Logic (10 mins)

  • Route by policy ownership and issue type.
  • Escalate urgent time-bound issues (deadlines, status holds).
  • Use explicit "needs human review" conditions.

Challenge 3: Produce Handoff Summaries (10 mins)

  • Generate a concise case summary for staff.
  • Include student goal, constraints, and required next action.
  • Add confidence and source notes where helpful.

✅ Complete When

  • Agent runs multi-turn intake without unnecessary questions
  • Routing is consistent across 3 test scenarios
  • Handoff summary is clear enough for immediate staff action

Deliverable

Submit 3 test conversations and the generated handoff summaries (one per department path).
