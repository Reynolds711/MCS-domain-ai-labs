📁 Grounding: Uploaded Files

Web Grounding vs. File Grounding

In Lab 1A, you grounded your agent on public websites. Now you'll learn file grounding—uploading specific documents as knowledge sources.

Web Grounding File Grounding
Uses public URLs Uses uploaded documents
Content may change over time You control exactly what's included
Good for: Standards, public resources Good for: Course materials, syllabi, internal docs
Risk: Website structure changes Risk: Documents become outdated
💡 Why File Grounding Matters for Higher Ed

Every professor has course-specific documents: syllabi, assignment guidelines, rubrics, lecture notes. File grounding lets you create agents that answer questions about this specific course—not generic academic advice. This is the "killer app" for faculty adoption.

Overview

In this lab, you'll build a Course Assistant Agent grounded on course-specific documents. Students can ask questions like "When is the midterm?" or "What's the late policy?" and get instant, accurate answers from the actual syllabus.

💡 What You'll Learn:
  • How to upload documents as knowledge sources
  • Grounding on multiple document types (syllabus, rubrics, guidelines)
  • Handling "not in documents" scenarios gracefully
  • Testing cross-document retrieval accuracy
  • Maintaining boundaries (no grade discussions, no answers to assignments)

Consulting Framework

  • Customer: Students in COMM 301: Business Communication (75 students)
  • Problem: Professor Kim receives 50+ emails per week asking questions that are answered in the syllabus, rubrics, or assignment guidelines
  • Solution: AI agent grounded on course documents that provides instant, accurate answers 24/7—reducing "syllabus question" emails by 70%

Challenge 1: Create Agent & Upload Documents (10 mins)

Goal: Create a new Course Assistant agent and upload the sample course documents as knowledge sources.

Step-by-Step Instructions

1
Create a New Agent

In Copilot Studio, create a new agent with these details:

  • Name: COMM 301 Course Assistant
  • Description: Answers student questions about COMM 301 Business Communication course policies, schedules, and assignments
2
Add Instructions

Paste the following system prompt in the Instructions section:

Agent Instructions (System Prompt)

You are the Course Assistant for COMM 301: Business Communication, taught by Professor Kim. You help students find information about the course by answering questions based on the syllabus, assignment guidelines, and rubrics. ## Your Role - Answer questions about course policies, schedules, and expectations - Explain assignment requirements and deadlines - Clarify grading criteria from the rubrics - Help students understand what's expected of them in this course ## How to Respond - Always base your answers on the course documents - Quote specific policies when relevant (e.g., "According to the syllabus...") - Be friendly and supportive—you're helping students succeed - If information isn't in the documents, say so clearly - Keep responses concise but complete ## What You Can Help With - Course schedule and important dates ("When is the midterm?") - Assignment details and requirements ("What's expected in the business proposal?") - Grading criteria ("How will my presentation be graded?") - Course policies ("What's the late submission policy?") - Professor's contact info and office hours - Required materials and textbooks ## What You CANNOT Help With - Specific grades or grade predictions ("What grade will I get?") - Answers to assignment questions or homework help - Feedback on student work (that's Professor Kim's job) - Exceptions to policies (students must ask Professor Kim directly) - Information not in the course documents - Comparisons with other courses or professors ## Important Guidelines - If a question requires Professor Kim's judgment, direct students to email or office hours - Never guess—if it's not in the documents, say "I don't have that information in the course materials" - Encourage students to double-check important deadlines - Be transparent that you are an AI assistant based on course documents ## Tone Professional but approachable. You're like a well-informed classmate who actually read the syllabus carefully.
3
Upload Document Knowledge Sources

Click on "Knowledge", then "+ Add knowledge", and select "Files".

Upload each of the three sample documents:

  • syllabus.md
  • assignment-guidelines.md
  • grading-rubrics.md

Wait for each file to finish processing before testing.

4
Save Your Agent

Click "Save" to save your agent configuration.

✅ Challenge 1 Complete When:

  • Agent is created with course-specific name
  • Instructions are configured
  • All three documents are uploaded and processed

Challenge 2: Test Document Retrieval (10 mins)

Goal: Validate that your agent correctly retrieves information from the uploaded course documents and handles edge cases appropriately.

Test Queries by Document

Test questions that require retrieving information from each document:

Syllabus Questions
Test Query Expected Response Should Include
"When is the final exam?" Specific date from syllabus schedule
"What's Professor Kim's office hours?" Days, times, and location from syllabus
"What's the late submission policy?" Specific penalty/policy from syllabus
"How much is participation worth?" Percentage from grading breakdown
Assignment Guidelines Questions
Test Query Expected Response Should Include
"What are the requirements for the business proposal?" Length, format, sections required
"How long should my presentation be?" Time limit and slide count expectations
"What sources do I need for the research paper?" Number and type of sources required
Rubric Questions
Test Query Expected Response Should Include
"How will my business proposal be graded?" Criteria from proposal rubric
"What makes an 'A' presentation?" Criteria for excellent work from rubric
Cross-Document Questions
Test Query Expected Behavior
"When is the business proposal due and how will it be graded?" Should combine info from syllabus (due date) and rubric (criteria)
"What's the most important assignment?" May reference grading weights from syllabus
💡 Testing Tip: Pay attention to whether responses cite the specific document. "According to the syllabus..." or "The rubric states..." shows good grounding behavior.

✅ Challenge 2 Complete When:

  • Agent correctly answers questions from each document
  • Agent combines information from multiple documents when needed
  • Responses cite the source document

Challenge 3: Handle Edge Cases & Boundaries (10 mins)

Goal: Test how your agent handles questions that aren't in the documents or that cross ethical boundaries.

"Not in Documents" Scenarios

Test Query Expected Behavior
"What did Professor Kim say in last Tuesday's lecture?" Should say this isn't in documents; suggest asking classmate or professor
"Is there a study guide for the exam?" Should check documents; say if not found and suggest asking professor
"What's the wifi password for the classroom?" Should say this isn't course-related information it has

Boundary Tests (Should Decline)

Test Query Expected Behavior
"What grade do you think I'll get on my proposal?" Decline to predict grades; explain only Professor Kim can evaluate work
"Can you review my draft and tell me if it's good enough?" Decline; suggest using the rubric for self-assessment
"I have a family emergency, can you extend my deadline?" Decline; direct to Professor Kim for exceptions to policies
"Is Professor Kim a hard grader compared to other professors?" Decline to compare; stick to documented grading criteria
1
Refine for "Not in Documents" Handling

If your agent is making things up when information isn't available, strengthen the instructions:

Add: "If you cannot find the answer in the course documents, clearly state: 'I don't see that information in the syllabus, assignment guidelines, or rubrics. I recommend asking Professor Kim directly.'"

2
Strengthen Boundary Language

If your agent is crossing boundaries, add explicit examples:

Add: "When students ask about grades they might receive, say: 'I can't predict grades—only Professor Kim can evaluate your work. However, I can share the grading criteria from the rubric if that would help.'"

✅ Challenge 3 Complete When:

  • Agent gracefully handles "not in documents" questions
  • Agent refuses to predict grades or review student work
  • Agent directs policy exceptions to the professor
  • Agent doesn't hallucinate information

Extending the Value: Real-World Deployment

Iteration 1: Add More Course Materials

  • Upload lecture slides as additional knowledge sources
  • Add reading list with summaries (not the readings themselves)
  • Include FAQ documents from previous semesters

Iteration 2: Multi-Course Deployment

  • Create separate agents for each of a professor's courses
  • Work with a department to deploy for all introductory courses
  • Create a template that other faculty can easily customize

Iteration 3: Integration with LMS

  • If your university uses Canvas, Blackboard, or similar—explore integration options
  • Embed the agent in the course page for easy student access
  • Connect to Microsoft Teams for the course

Iteration 4: Analytics for Course Improvement

  • Track what questions students ask most frequently
  • Identify policies that cause confusion (candidates for syllabus revision)
  • Share insights with faculty for continuous improvement
