Guided Practice Framework

  • Start with the customer: Teacher, counselor, attendance lead, or family-facing staff.
  • Define the bottleneck: High-volume repetitive work that creates instructional drag.
  • Run the right build mode: Prompting, Studio Lite grounding, or multi-turn orchestration.

🧠 Copilot 101: Prompt Engineering

Prompt-only labs that build clarity, specificity, and reusable prompting habits for everyday teacher workflows.

101-A: Lesson Plan to Sub Plan Journey

⏱️ 15 mins

Persona: Classroom Teacher

Transform a generic lesson-plan prompt into a substitute-ready plan that any adult can execute confidently.

  • Guided Practice: Start with a basic lesson prompt for grade, subject, and time block.
  • Guided Practice: Add objectives, materials, pacing, and classroom-specific context.
  • Guided Practice: Reframe for substitute clarity and compare first versus final output.
Strategic Goal: Give Teachers Time Back
ROI: Sub plan drafted in 5 minutes instead of 45

101-B: Letter of Recommendation

⏱️ 15 mins

Persona: Classroom Teacher

Build a structured recommendation prompt that preserves teacher voice while adding student-specific evidence.

  • Guided Practice: Start from a one-line recommendation request.
  • Guided Practice: Add student achievements, audience context, and desired tone.
  • Guided Practice: Require concrete examples and compare generic versus specific output.
Strategic Goal: Give Teachers Time Back
ROI: Letter drafted in 10 minutes, personalized and ready to review

🏗️ Copilot 301: Copilot Studio

Multi-turn and multi-source builds tied to teaching, attendance, and support workflows with explicit build-order context.

301-1: Lesson Planner Agent (Lp)

⏱️ 30-35 mins

Persona: Classroom Teacher

Build a multi-turn lesson planning agent combining standards grounding with uploaded curriculum guides.

  • Guided Practice: Ask grade, subject, objectives, and time block in sequence.
  • Guided Practice: Return full lesson with differentiation guidance and materials map.
  • Build Order: Before Lo (Period 1), this Lp (Period 4), after Tu (Period 5).
Strategic Goal: Give Teachers Time Back
ROI: 3-5 hours saved per week per teacher

Getting Started

Prerequisites

  • Access to Copilot Chat and Copilot Studio.
  • Sample lesson, standards, and communication documents for practice.
  • One facilitator and one note-taker for each small team.

Recommended Learning Path

  1. Run one 101 lab to establish prompt quality habits.
  2. Run both 201 builds to practice web and file grounding.
  3. Run one 301 orchestration lab with handoff criteria.
  4. Choose one extension and scope a 2-week pilot.

⚠️ Responsible K12 AI Practices

  • Protect student privacy and avoid personally identifiable data in prompts.
  • Keep educators in the loop for all high-stakes decisions.
  • Use plain language to support clear communication across families.

Measuring K12 Impact

Use simple metrics during pilots to show value quickly.

Time Back

Minutes saved per lesson, communication draft, or support intake.

Consistency

Quality and completeness of plans, family notes, and intervention summaries.

Early Action

Reduced delay from issue detection to intervention decision.

Family Engagement

Improved response quality and follow-through across communication touchpoints.
