Consulting Framework

Getting Started

Prerequisites

  • Access to Microsoft Copilot Studio (or compatible AI platform)
  • Basic understanding of declarative agents and AI prompting
  • Familiarity with K-12 education context (helpful but not required)

Recommended Learning Path

  1. Start with: Teacher Productivity Agent (30 mins)
  2. Then try: School Operations Agent (30 mins)
  3. Advance to: Student Support Navigator (35 mins)

⚠️ Ethical Guidelines for K-12 AI Agents

All labs emphasize responsible AI practices:

  • Augment, don't replace: Agents assist educators, never make decisions
  • Transparency: Always disclose when AI is being used
  • Privacy first: Never use real student data in labs
  • Human oversight: Teachers review all AI-generated content
  • Equity focus: Ensure agents serve all students and families
