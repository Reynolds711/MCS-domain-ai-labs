📄 Lab 1B: Build a File-Grounded Lesson Planning Agent

⏱️ Duration: 30 minutes

📁 Grounding: File Sources

What is a Declarative Agent?

A declarative agent is an AI assistant you create by describing what it should do rather than writing code. You configure:

  • Instructions: Tell the agent its role, capabilities, and boundaries
  • Knowledge: Connect data sources the agent can reference (websites, documents)
  • Actions: (Optional) Enable the agent to take actions like creating documents
💡 Why File Grounding for Education

Schools have years of institutional knowledge locked in documents: lesson templates, rubrics, curriculum guides, and scope & sequence charts. File-grounded agents can access all of this—providing teachers with your school's specific resources, not generic internet content.

Overview

In this lab, you'll build a declarative agent using uploaded document knowledge sources. Your agent will help teachers with lesson planning by referencing your school's actual templates, rubrics, and curriculum documents.

💡 What You'll Learn:
  • Uploading documents as knowledge sources in Copilot Studio
  • Creating agents grounded on school-specific resources
  • Writing prompts that reference multiple documents effectively
  • Testing cross-document retrieval and accuracy
  • Validating that responses match your source materials

Consulting Framework

  • Customer: Lincoln Middle School teachers and instructional coaches
  • Problem: Teachers recreate lesson planning resources from scratch instead of using school-approved templates; new teachers don't know what resources exist
  • Solution: AI agent grounded on school documents that helps teachers find templates, rubrics, and examples while maintaining consistent format school-wide

Challenge 1: Create Agent with Document Knowledge (10 mins)

Goal: Create a new declarative agent and upload the sample documents as knowledge sources.

Step-by-Step Instructions

1
Open Copilot Studio

Navigate to copilotstudio.microsoft.com and sign in with your Microsoft account.

2
Create a New Agent

Click "Create" in the left navigation, then select "New agent".

Choose "Skip to configure" to manually set up your agent.

3
Name Your Agent

Enter the following details:

  • Name: Lesson Planning Assistant
  • Description: Helps teachers find and use school-approved lesson planning resources
  • Icon: Choose a planning or document-themed icon
4
Add Instructions

In the Instructions section, paste the following system prompt:

Agent Instructions (System Prompt)

You are the Lesson Planning Assistant for Lincoln Middle School. You help teachers with lesson planning by providing information from our school's official planning documents, templates, and rubrics. ## Your Role - Help teachers find the right planning template for their needs - Explain how to use our standard lesson plan format - Provide example rubrics from our school's rubric collection - Clarify standards alignment using our crosswalk documents - Answer questions about school planning expectations ## How to Respond - Always reference the specific document you're drawing information from - Quote relevant sections directly when helpful - Explain WHY we use specific formats (the pedagogical reasoning) - Provide concrete examples from the documents - Keep responses focused on what's in the documents ## What You Can Help With - Finding the right template section for a specific need - Explaining rubric criteria and how to use them - Clarifying standards crosswalk mappings - Describing our differentiation expectations - Answering "how do I..." questions about planning ## What You Cannot Do - Create new templates or rubrics (you reference existing ones) - Approve lesson plans or say if they meet expectations - Modify the official documents - Make up information not in the documents - Replace instructional coach feedback ## Important Guidelines - If information isn't in the documents, say so clearly - Encourage teachers to consult instructional coaches for approval questions - Be supportive and helpful—teachers are busy - Remind teachers that these are our school's formats, but they should adapt to student needs ## Available Documents - Lesson Plan Template (school standard format) - Rubric Samples (writing, projects, presentations, participation) - Standards Crosswalk (Common Core to state standards mapping)
5
Upload Document Knowledge Sources

Click on "Knowledge" in the agent configuration. Then click "+ Add knowledge" and select "Files".

Upload all three sample files:

  • lesson-plan-template.md
  • rubric-samples.md
  • standards-crosswalk.md

Each file will be processed and indexed for retrieval.

6
Save Your Agent

Click "Create" or "Save" to save your agent configuration.

✅ Challenge 1 Complete When:

  • Your agent is created with the name "Lesson Planning Assistant"
  • Instructions are configured with the system prompt above
  • All three sample files are uploaded as knowledge sources
  • Files are showing as "Ready" or "Indexed" in the Knowledge panel

Challenge 2: Test Cross-Document Retrieval (10 mins)

Goal: Validate that your agent correctly retrieves information from the right documents and synthesizes information across sources when needed.

Step-by-Step Instructions

1
Open the Test Panel

In Copilot Studio, click the "Test" button to open the chat panel.

2
Test Single-Document Queries

Start with questions that should retrieve from one specific document:

Single-Document Test Queries

Test Query Expected Source What to Look For
"What sections should I include in my lesson plan?" Lesson Plan Template Lists all sections: Header, Objectives, Standards, etc.
"Show me a rubric for student presentations" Rubric Samples Provides the Presentation Rubric with criteria and levels
"How does CCSS.ELA-LITERACY.W.7.1 map to our state standards?" Standards Crosswalk Shows the mapping for 7th grade argumentative writing
3
Test Cross-Document Queries

Now try questions that require information from multiple documents:

Cross-Document Test Queries

Test Query Expected Sources What to Look For
"I'm planning a writing lesson. What template sections do I need and what rubric should I use?" Template + Rubric Samples Describes lesson plan format AND suggests the Writing Rubric
"How do I document differentiation and assess it?" Template + Rubric Samples Explains differentiation section AND mentions how rubrics can be modified
"Help me align a 7th grade ELA lesson to both Common Core and state standards" Template + Crosswalk Explains standards section AND shows crosswalk mapping
4
Validate Accuracy

For at least 2 responses, manually check that the information matches what's in the source documents. This validates grounding quality.

✅ Challenge 2 Complete When:

  • Agent correctly retrieves from individual documents
  • Agent synthesizes information across documents when appropriate
  • Agent cites which document it's referencing
  • You've manually verified at least 2 responses match source documents

Challenge 3: Handle Edge Cases & Boundaries (10 mins)

Goal: Test how your agent handles requests that push beyond the documents and validate appropriate boundary-setting.

Step-by-Step Instructions

1
Test "Not in Documents" Scenarios

Ask questions where the answer isn't in your uploaded documents:

Out-of-Scope Test Queries

Test Query Expected Behavior
"What's the best way to teach fractions?" Acknowledge this isn't in the documents; suggest consulting instructional coaches
"Can you create a new rubric for science labs?" Explain it can only reference existing rubrics; can't create new ones
"Is my lesson plan good enough?" Decline to evaluate; explain instructional coaches approve plans
"Change the template to have more sections" Explain it can't modify official documents
2
Test Ethical Boundaries

Try scenarios that test appropriate boundaries for education AI:

Ethical Boundary Tests

Edge Case Expected Behavior
"Write my entire lesson plan for me" Offer to help with specific sections; explain teacher ownership
"How should I grade this student's work?" Explain rubric criteria but decline to assign grades
"Create fake student work samples for my rubric" Decline; explain it provides real examples from documents only
3
Refine If Needed

If the agent doesn't handle these appropriately, update your Instructions to be more explicit about boundaries.

✅ Challenge 3 Complete When:

  • Agent clearly states when information isn't in the documents
  • Agent doesn't make up content outside the source files
  • Agent appropriately declines evaluation/judgment requests
  • Agent maintains helpful tone while setting boundaries

⚖️ Ethical Boundaries for Document-Grounded Agents

Grounded Means Limited

File-grounded agents should only provide information from their source documents. When asked about something not in the documents, they should say so—not make up answers. This maintains trust and accuracy.

Templates Guide, Teachers Decide

The agent helps teachers find and understand templates, but it never approves lesson plans or says a plan "meets expectations." That's a professional judgment only instructional leaders can make.

Rubrics Describe, Not Prescribe

The agent can explain rubric criteria and what each level means, but it should never assign grades or evaluate student work. Grading is a teacher responsibility that requires professional judgment.

📋 Document Grounding Checklist

  • Agent cites source documents in responses
  • Agent admits when information isn't in documents
  • Agent doesn't fabricate content
  • Agent doesn't evaluate or approve teacher work
  • Agent directs evaluation questions to instructional leaders

Comparison: Web vs. File Grounding

Aspect Web Grounding (Lab 1A) File Grounding (This Lab)
Best For Public information (standards, regulations) Internal documents (templates, policies)
Content Control Limited (external sites may change) Full (you control the documents)
Updates Automatic (re-crawls websites) Manual (re-upload changed files)
School-Specific No (generic public info) Yes (your school's actual resources)

🌟 Optional Extension: Adding Topics (15 mins)

Add structured Topics to handle common planning scenarios with consistent, high-quality responses.

Topic Idea: "Start My Lesson Plan"

Create a guided Topic that walks teachers through the planning process:

1
Create New Topic

In Copilot Studio, go to Topics → + Add a topic → From blank

2
Add Trigger Phrases

Name: "Start Lesson Plan"
Trigger phrases:

  • start a new lesson plan
  • help me plan a lesson
  • I need to create a lesson
  • walk me through lesson planning
3
Build Conversation Flow

Add questions to gather context:

Question 1: "What subject and grade level?" Question 2: "What topic or unit are you teaching?" Question 3: "How long is the lesson? (one class, multi-day, etc.)" Question 4: "What type of assessment will you use?" Based on answers → Provide relevant template sections and rubric suggestions

More Topic Ideas

  • Find a Rubric: "I need a rubric for..." → Asks assessment type → Returns matching rubric
  • Differentiation Helper: "How do I differentiate..." → Explains the differentiation section with examples
  • Template Section Explainer: "Explain the [section] part of the template" → Deep dive into one section
