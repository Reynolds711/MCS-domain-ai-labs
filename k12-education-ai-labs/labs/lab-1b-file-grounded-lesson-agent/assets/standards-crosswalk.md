## PURPOSE OF THIS DOCUMENT

This crosswalk helps teachers understand how Common Core State Standards (CCSS) align with our state standards and district assessment expectations. Use this document to:

1. Ensure lessons address both national and state requirements
2. Understand assessment priorities for each standard
3. Identify standards that require additional emphasis
4. Plan for vertical alignment across grade levels

## ASSESSMENT PRIORITY KEY

| Priority | Meaning | Instructional Time | Assessment Weight |
|----------|---------|-------------------|-------------------|
| **HIGH** | Assessed on state/district assessments; foundational for future learning | 60-70% of instruction | Major grade component |
| **MEDIUM** | Important for grade-level mastery; some assessment coverage | 20-30% of instruction | Moderate grade component |
| **LOW** | Supporting standards; integrated into other instruction | 10% of instruction | Minor or embedded |

## HOW TO USE THIS CROSSWALK

### For Lesson Planning
1. Identify the Common Core standard(s) your lesson addresses
2. Find the corresponding state standard in the crosswalk
3. Note the assessment priority to determine emphasis
4. Read the notes for specific expectations
5. Include both standard IDs in your lesson plan

### For Assessment Design
1. Focus formative assessments on HIGH priority standards
2. Ensure unit assessments cover all HIGH priority standards
3. Use MEDIUM priority standards for practice and application
4. Integrate LOW priority standards naturally into instruction

### For Differentiation
- HIGH priority standards require mastery for all students
- Scaffold instruction to ensure all students access HIGH priority content
- Use MEDIUM priority standards for extension with advanced learners

## VERTICAL ALIGNMENT NOTES

### ELA Writing Progression
- **Grade 6:** Introduce claims, basic evidence, simple organization
- **Grade 7:** Add counterclaims, logical reasoning, sophisticated organization
- **Grade 8:** Precise claims, credible sources, cohesion, high school readiness

### Math Progression
- **Grade 6:** Ratio concepts, variables, one-step equations
- **Grade 7:** Proportional relationships, rational numbers, two-step equations
- **Grade 8:** Linear functions, systems, Pythagorean Theorem, Algebra 1 readiness
