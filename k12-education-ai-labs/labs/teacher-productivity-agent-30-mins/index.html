Teacher Productivity Agent

📚 Build a Teacher Productivity Agent

⏱️ Duration: 30 minutes
📊 Level: Beginner
🎯 3 Challenges

Overview

In this hands-on lab, you'll build a declarative AI agent that saves teachers time on lesson planning, rubric creation, and parent communications. Your agent will help educators focus more on teaching and less on administrative tasks.

💡 What You'll Learn:
  • How to design AI agents for education-specific use cases
  • Aligning content to academic standards using AI
  • Creating tone-appropriate communications for different audiences
  • Implementing responsible AI boundaries in education

Consulting Framework

  • Customer: K-12 Teachers (all subjects, grades 6-12)
  • Problem: Teachers spend 3-5 hours/week on lesson planning, rubric creation, and parent communications
  • Solution: AI agent that drafts standards-aligned materials and communications, reducing prep time by 60%

Prerequisites

  • Access to Microsoft Copilot Studio (or compatible AI platform)
  • Basic understanding of AI agents and prompting
  • Familiarity with educational standards (helpful but not required)
  • Code editor (VS Code recommended)

Lab Scenario

You're consulting for Lincoln Middle School, a public school serving grades 6-8 with 450 students. Teachers report spending excessive time on lesson planning, rubric creation, and parent communications—time that could be spent on instruction and student support.

Your task is to build an AI agent that assists teachers with these repetitive tasks while maintaining appropriate educational standards and ethical boundaries.

Challenge 1: Lesson Plan Alignment Assistant (10 mins)

Scenario: Teachers need to create lesson plans aligned to state standards (Common Core, NGSS, etc.). Currently, they manually cross-reference standards documents, which takes significant time. Build an agent that helps align lesson topics to appropriate standards.

Tasks

  1. Review the sample state standards data structure below
  2. Create a declarative agent with a system prompt that understands educational standards
  3. Configure the agent to suggest relevant standards for lesson topics
  4. Test with the sample queries provided

Sample State Standards Data

{ "standard_id": "CCSS.ELA-LITERACY.RL.8.1", "grade": "8", "subject": "English Language Arts", "domain": "Reading: Literature", "standard": "Cite the textual evidence that most strongly supports an analysis of what the text says explicitly as well as inferences drawn from the text.", "description": "Students analyze text and cite specific evidence to support their analysis and inferences.", "keywords": ["textual evidence", "inference", "analysis", "citing sources"], "example_activities": [ "Close reading with annotation", "Evidence-based discussion", "Literary analysis essay" ] }

Sample System Prompt

You are a Lesson Planning Assistant for K-12 teachers. You help teachers align their lesson topics to appropriate state standards. Your capabilities: - Suggest relevant standards for lesson topics - Explain standards in teacher-friendly language - Recommend activities that address specific standards - Identify cross-curricular standard connections When answering: - Always cite the specific standard ID - Explain WHY the standard fits the lesson topic - Suggest 2-3 concrete activities aligned to the standard - Use clear, educator-friendly language Ethical boundaries: - You assist with planning, you don't replace teacher judgment - Always encourage teachers to review and customize suggestions - Never claim a lesson "fully addresses" a standard without teacher review Available data: State standards database including Common Core (ELA & Math), NGSS (Science), and state-specific social studies standards.

Test Queries

  • "I'm teaching a unit on persuasive writing for 8th grade. Which standards apply?"
  • "What activities align with CCSS.ELA-LITERACY.RL.8.1?"
  • "I want to teach photosynthesis to 7th graders. What are the relevant NGSS standards?"
  • "Can you suggest cross-curricular connections between this ELA standard and science?"

✅ Success Criteria

  • Agent accurately identifies relevant standards for lesson topics
  • Agent cites specific standard IDs and explains alignment
  • Agent suggests concrete, grade-appropriate activities
  • Agent maintains appropriate boundaries (assists, doesn't decide)
💡 Tip: Use grounding/RAG to connect your agent to standards databases. In Copilot Studio, add your standards JSON as a knowledge source. The agent should retrieve and explain standards, not just list them.

⚠️ Ethical Boundary

The agent assists; the teacher decides. Never claim a lesson "fully meets" a standard. Teachers must review all suggestions and adapt to their students' needs. Always include disclaimers about teacher review.

Challenge 2: Rubric Builder & Feedback Generator (10 mins)

Scenario: Creating assessment rubrics is time-consuming. Teachers need rubrics that clearly define performance levels and align with standards. Build an agent that generates draft rubrics and provides feedback examples.

Tasks

  1. Review sample rubric structures and criteria
  2. Update your agent's system prompt to handle rubric generation
  3. Configure the agent to generate standards-aligned rubrics
  4. Test rubric generation for various assignment types

Sample Rubric Structure

{ "assignment": "Persuasive Essay - 8th Grade ELA", "aligned_standards": ["CCSS.ELA-LITERACY.W.8.1"], "total_points": 20, "criteria": [ { "criterion": "Thesis Statement", "weight": 4, "levels": { "exemplary": { "points": 4, "descriptor": "Clear, compelling thesis with nuanced claim that addresses counterarguments" }, "proficient": { "points": 3, "descriptor": "Clear thesis statement with identifiable claim" }, "developing": { "points": 2, "descriptor": "Thesis present but unclear or too broad" }, "beginning": { "points": 1, "descriptor": "Thesis missing or does not make a claim" } } }, { "criterion": "Evidence & Citations", "weight": 5, "levels": { "exemplary": { "points": 5, "descriptor": "Multiple relevant sources cited correctly; evidence strongly supports claim" }, "proficient": { "points": 4, "descriptor": "Sources cited with minor errors; evidence supports claim" }, "developing": { "points": 3, "descriptor": "Some sources cited; evidence partially supports claim" }, "beginning": { "points": 1, "descriptor": "Few or no sources; weak connection to claim" } } } ] }

Extended System Prompt Addition

You also help teachers create assessment rubrics and draft feedback. For rubric generation: - Create 4-level rubrics (Exemplary, Proficient, Developing, Beginning) - Align criteria to specific standards - Use clear, observable descriptors - Suggest point distributions based on assignment importance For feedback generation: - Provide specific, actionable feedback examples for each rubric level - Use growth-oriented language - Reference specific criteria from the rubric - Suggest next steps for improvement Always include: - A note that teachers should customize for their students - Reminder to use student-friendly language when sharing rubrics - Suggestion to review rubric with students before assignment

Test Queries

  • "Generate a rubric for an 8th grade persuasive essay aligned to CCSS.ELA-LITERACY.W.8.1"
  • "Create a rubric for a 7th grade science lab report on photosynthesis"
  • "What feedback should I give a student who scored 'Developing' on thesis statement?"
  • "How should I weight criteria for a research project rubric?"

✅ Success Criteria

  • Agent generates rubrics with clear, measurable criteria
  • Rubric criteria align to specified standards
  • Performance level descriptors are specific and observable
  • Agent provides actionable feedback examples
  • Agent reminds teachers to customize and review with students
⚠️ Important: Rubrics are teaching tools, not just grading instruments. The agent should encourage teachers to share rubrics with students before assignments to clarify expectations. This promotes equity and student agency.

Challenge 3: Parent Communication Drafting Agent (10 mins)

Scenario: Teachers send dozens of parent emails weekly about academic progress, behavior, events, and concerns. Drafting professional, tone-appropriate communications takes significant time. Build an agent that helps draft parent communications with appropriate tone control.

Tasks

  1. Review sample parent communication templates
  2. Configure the agent to draft emails with tone control
  3. Test with various communication scenarios (positive, concern, informational)
  4. Verify appropriate professional tone

Sample Communication Templates

{ "communication_type": "academic_progress", "tone": "positive", "template": { "subject": "Great Progress in [Subject]!", "opening": "I wanted to share some wonderful news about [Student Name]'s progress in [Subject].", "body": "[Specific examples of progress, growth, or achievement]", "closing": "Please let me know if you have any questions. I'm excited to see [Student Name]'s continued growth!", "signature": "[Teacher Name]\n[Subject] Teacher\n[Contact Information]" } } { "communication_type": "concern", "tone": "constructive", "template": { "subject": "Let's Work Together - [Student Name]'s [Subject]", "opening": "I'm reaching out because I'd like to partner with you to support [Student Name]'s success in [Subject].", "body": "[Specific, observable behaviors or patterns - no judgment]\n\nI believe together we can help [Student Name] by [specific strategies].", "closing": "I'm confident we can support [Student Name]'s growth. Could we schedule a brief call to discuss?", "signature": "[Teacher Name]" } }

Parent Communication System Prompt Addition

You also help teachers draft parent communications. Communication principles: - Use respectful, professional tone - Be specific with examples (avoid vague statements) - Focus on partnership and collaboration - For concerns: describe behaviors, not character judgments - For positive news: celebrate specific achievements - Always end with an invitation for dialogue Tone guidelines: - POSITIVE: Warm, enthusiastic, specific - CONCERN: Constructive, solution-focused, collaborative - INFORMATIONAL: Clear, concise, helpful Always include: - A reminder for teachers to personalize before sending - Note to review for cultural sensitivity - Suggestion to consider translation if needed - Reminder that this is a DRAFT requiring teacher review What NOT to do: - Never diagnose students - Never guarantee outcomes - Never use educational jargon parents may not understand - Never discuss other students

Test Queries

  • "Draft a positive email about a student who improved their essay writing skills"
  • "Write an email to parents about a student who isn't turning in homework"
  • "Create an informational email about an upcoming field trip to a science museum"
  • "Draft an email requesting a parent-teacher conference about reading struggles"

✅ Success Criteria

  • Agent generates professional, respectful communications
  • Tone matches communication type (positive, concern, informational)
  • Language is clear and free of educational jargon
  • Concern emails focus on behaviors, not judgments
  • All drafts include partnership language and dialogue invitations
  • Agent reminds teachers to review and personalize
💡 Cultural Sensitivity Tip: Encourage teachers to consider families' preferred communication methods (email, phone, text) and language needs. The agent should remind teachers that translation may be needed and to consider cultural context when discussing student behavior or expectations.

⚠️ Critical Ethical Boundary

Never send AI-generated emails without teacher review. Parent communications require human judgment, cultural awareness, and personalization. Teachers must review, edit, and personalize all drafts. The agent should never claim emails are "ready to send."
