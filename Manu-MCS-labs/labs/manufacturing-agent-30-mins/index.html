Manufacturing Intelligence Agent

🏭 Build a Manufacturing Intelligence Agent

⏱️ Duration: 30 minutes
📊 Level: Beginner
🎯 3 Challenges

Overview

In this hands-on lab, you'll build a declarative AI agent that assists manufacturing floor managers with real-time insights and decision-making. Your agent will help monitor equipment maintenance, optimize production lines, and provide quality control intelligence.

💡 What You'll Learn:
  • How to design declarative agents for domain-specific use cases
  • Integrating structured manufacturing data with AI agents
  • Creating conversational interfaces for technical queries
  • Implementing industry-specific knowledge bases

Prerequisites

  • Access to Microsoft Copilot Studio
  • Basic understanding of AI agents and prompting
  • Familiarity with JSON data structures (helpful but not required)

Lab Scenario

You work for Contoso Manufacturing, a mid-sized manufacturer producing automotive parts. The company operates multiple production lines with various CNC machines, hydraulic presses, and assembly equipment. Floor managers need quick access to equipment maintenance schedules, production metrics, and quality control data.

Your task is to build an intelligent agent that can answer questions and provide insights using the company's manufacturing data.

Challenge 1: Equipment Maintenance Assistant (10 mins)

Scenario: Floor managers need quick answers about equipment maintenance schedules, history, and upcoming service requirements. Build an agent that can answer maintenance-related questions using the equipment database.

Tasks

  1. Review the sample equipment data structure below
  2. Create a declarative agent with a system prompt that understands maintenance terminology
  3. Configure the agent to access equipment maintenance data
  4. Test with the sample queries provided

Sample Equipment Data

{ "equipment_id": "CNC-003", "name": "CNC Milling Machine", "location": "Production Line 3", "status": "operational", "last_maintenance": "2026-01-10", "next_maintenance": "2026-02-10", "maintenance_interval_days": 30, "maintenance_history": [ { "date": "2026-01-10", "type": "preventive", "technician": "John Smith", "notes": "Replaced coolant, checked spindle alignment", "duration_hours": 2.5 } ], "common_issues": [ "Spindle overheating", "Tool changer jamming", "Coolant pump failure" ] }

Sample System Prompt

You are a Manufacturing Maintenance Assistant for Contoso Manufacturing. You help floor managers and maintenance teams with equipment-related questions. Your capabilities: - Provide maintenance schedules and history - Explain common equipment issues and solutions - Recommend preventive maintenance actions - Calculate time until next maintenance When answering: - Be concise and actionable - Include specific dates and equipment IDs - Highlight urgent maintenance needs - Use manufacturing terminology appropriately Available data: Equipment database with maintenance history, schedules, and specifications for all production line machinery.

Test Queries

  • "When was the last maintenance on CNC-003?"
  • "Which equipment needs maintenance in the next 7 days?"
  • "What are the common issues with our CNC machines?"
  • "Who performed the last maintenance on Line 3 equipment?"

✅ Success Criteria

  • Agent accurately retrieves maintenance dates from equipment data
  • Agent references specific equipment IDs and locations
  • Agent provides actionable maintenance recommendations
  • Responses use appropriate manufacturing terminology
💡 Tip: Use grounding to connect your agent to the equipment data. In Copilot Studio, click Knowledge → Add knowledge and upload your equipment data files or connect to SharePoint where your maintenance records are stored.

Challenge 2: Production Line Optimizer (10 mins)

Scenario: Extend your agent to monitor and analyze production metrics. Floor managers need insights into OEE (Overall Equipment Effectiveness), bottlenecks, and optimization opportunities.

Tasks

  1. Add production metrics data to your agent's knowledge base
  2. Update the system prompt to handle OEE calculations and analysis
  3. Configure the agent to identify bottlenecks and suggest optimizations
  4. Test with production-related queries

Sample Production Metrics Data

{ "line_id": "Assembly-002", "shift": "day", "date": "2026-01-14", "metrics": { "planned_production_time": 480, "actual_production_time": 408, "downtime_minutes": 72, "ideal_cycle_time": 2.5, "total_units_produced": 145, "defective_units": 3, "oee": { "availability": 0.85, "performance": 0.89, "quality": 0.98, "overall": 0.74 } }, "downtime_reasons": [ { "reason": "Tool change", "duration_minutes": 25 }, { "reason": "Material shortage", "duration_minutes": 35 } ], "bottleneck_detected": true, "bottleneck_station": "Welding Station 2" }

OEE Calculation Reference

OEE = Availability × Performance × Quality Availability = (Actual Production Time / Planned Production Time) Performance = (Ideal Cycle Time × Total Units) / Actual Production Time Quality = (Good Units / Total Units Produced) World-class OEE: 85% or higher Typical OEE: 60% - 70% Low OEE: Below 60%

Extended System Prompt Addition

You also analyze production metrics and calculate OEE (Overall Equipment Effectiveness). For production analysis: - Calculate and explain OEE components (Availability, Performance, Quality) - Identify bottlenecks and their impact - Suggest specific optimization actions - Prioritize recommendations by potential impact When discussing OEE: - Compare to industry benchmarks (world-class = 85%+) - Highlight the weakest component needing improvement - Provide concrete next steps

Test Queries

  • "What's the OEE for Assembly Line 2 today?"
  • "Why is the OEE low? What's causing the most downtime?"
  • "Where is the bottleneck in our production?"
  • "How can we improve availability on Line 2?"
  • "Compare our OEE to world-class manufacturing standards"

✅ Success Criteria

  • Agent correctly calculates and explains OEE components
  • Agent identifies root causes of low OEE from downtime data
  • Agent provides specific, actionable optimization recommendations
  • Agent compares performance to industry benchmarks
⚠️ Note: When working with time-series production data, ensure your agent understands the temporal context. Specify which shift, date, or time period is being analyzed.

Challenge 3: Quality Control Intelligence (10 mins)

Scenario: Add quality control capabilities to help identify defect patterns, perform root cause analysis, and recommend corrective actions based on quality inspection data.

Tasks

  1. Integrate quality inspection data into your agent
  2. Configure the agent to identify defect trends and patterns
  3. Enable root cause analysis capabilities
  4. Test with quality-related queries

Sample Quality Data

{ "inspection_period": "2026-01-08 to 2026-01-14", "total_inspections": 1250, "defects_found": 37, "defect_rate": 0.0296, "defect_types": [ { "type": "Surface finish", "count": 15, "percentage": 40.5, "affected_products": ["Part-A127", "Part-B203"], "severity": "minor" }, { "type": "Dimensional tolerance", "count": 12, "percentage": 32.4, "affected_products": ["Part-C445"], "severity": "major" } ], "root_causes": [ { "defect_type": "Surface finish", "likely_cause": "Worn cutting tool on CNC-003", "recommended_action": "Replace cutting tool, verify surface finish parameters" } ], "trend": "increasing", "previous_week_defect_rate": 0.0189 }

Quality Analysis System Prompt Addition

You also perform quality control analysis using Six Sigma principles. For quality analysis: - Identify defect patterns and trends - Perform root cause analysis - Recommend corrective and preventive actions (CAPA) - Calculate defect rates and compare to targets Quality terminology you understand: - Defect rate, PPM (Parts Per Million) - Six Sigma levels (3.4 DPMO = Six Sigma) - Root cause analysis (5 Whys, Fishbone) - CAPA (Corrective and Preventive Actions) Target defect rate: < 2% (20000 PPM) World-class: < 0.5% (5000 PPM or Six Sigma 4.0+)

Test Queries

  • "What are the top defect types this week?"
  • "What's causing the dimensional tolerance issues?"
  • "How does our current defect rate compare to last week?"
  • "What corrective actions should we take for Part-A127 defects?"
  • "Is our quality improving or declining?"
  • "Which products have the most quality issues?"

✅ Success Criteria

  • Agent identifies defect patterns from quality data
  • Agent performs root cause analysis and suggests likely causes
  • Agent recommends specific corrective actions
  • Agent identifies trends (improving/declining quality)
  • Agent uses appropriate quality terminology (Six Sigma, PPM, etc.)
💡 Advanced Tip: Consider adding visual data interpretation capabilities. If your agent can analyze charts or graphs, you could provide Pareto charts showing the "vital few" defect types that cause the most issues.

🌟 Bonus Challenges

If you complete the main challenges early, try these advanced scenarios:

  • Multilingual Support: Add Spanish language support for global manufacturing sites
  • Predictive Alerts: Configure the agent to proactively alert when equipment is nearing maintenance due or quality trends are declining
  • Visual Dashboards: Integrate with a charting library to generate visual OEE or quality trend reports
  • Cross-functional Analysis: Correlate maintenance events with quality issues (e.g., "Do defects increase after equipment maintenance?")
  • Safety Integration: Add safety compliance checking (e.g., "Has CNC-003 had its safety inspection this month?")

🚀 Extending Value: Future Iterations

This lab uses Copilot Studio's built-in knowledge grounding. As your manufacturing AI maturity grows, consider these extensions:

Additional Knowledge Sources

  • SharePoint Integration: Connect to existing document libraries with SOPs, maintenance manuals, and safety procedures
  • Dataverse/Dynamics 365: Ground on live ERP data for real-time inventory and work order information
  • Custom Connectors: Connect to MES (Manufacturing Execution Systems) or SCADA data

Advanced Capabilities (200-Level)

  • Power Automate Actions: Enable your agent to create work orders or send alerts
  • Azure AI Services: Add computer vision for defect detection or anomaly detection for predictive maintenance
  • Custom APIs: Connect to IoT platforms for real-time sensor data

Potential Outcomes

  • Reduce unplanned downtime by 15-25% with predictive maintenance insights
  • Improve first-pass quality by catching defect patterns earlier
  • Enable self-service reporting, freeing supervisors for higher-value work
