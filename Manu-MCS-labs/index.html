Welcome to Manufacturing AI Labs

Learn to build declarative AI agents tailored for manufacturing industry challenges. These hands-on labs guide you through real-world scenarios including equipment maintenance, production optimization, quality control, and more.

Consulting Framework

Each lab answers three critical questions:

  • Who is the customer? Operators, supervisors, engineers, or managers
  • What repetitive, high-volume problem exists? Clear pain points
  • What agent can remove friction using existing data? Measurable solutions

🎯 100-Level Labs: Start Here

New to building AI agents? Start with these foundational labs that teach you to create declarative agents in Microsoft Copilot Studio—no coding required.

Start Here

Lab 1A: Web-Grounded Manufacturing Excellence Agent

⏱️ 30 mins

Build your first declarative agent using public manufacturing websites. Help operators and supervisors understand OEE, quality concepts, and lean manufacturing principles.

  • Create agent in Copilot Studio
  • Ground on public web sources
  • Use evaluation tools to test
  • Set safety and ethical boundaries
Customer: Production Supervisors & Operators
Grounding: Web Sources (OEE.com, ASQ.org, Lean.org)
ROI: 5+ hours/week saved on repetitive expert questions
Start Lab 1A Beginner
After Lab 1A

Lab 1B: File-Grounded Equipment Assistant Agent

⏱️ 30 mins

Build an agent grounded on your plant's actual documents—equipment manuals, maintenance schedules, and quality procedures. Provide instant access to plant-specific information.

  • Upload document knowledge sources
  • Test cross-document retrieval
  • Handle "not in documents" scenarios
  • Enforce safety documentation limits
Customer: Operators & Maintenance Technicians
Grounding: Uploaded Files (manuals, schedules, procedures)
ROI: Document search time reduced by 80%
