Lab 1B: File-Grounded Operations Knowledge Agent

📁 Lab 1B: Build a File-Grounded SMB Operations Knowledge Agent

⏱️Duration: 30 minutes
📊Level: 100 - Beginner
📄Grounding: Uploaded Files

Overview

In this lab, you will build an internal operations assistant grounded on your own business documents so team members can get consistent answers instantly.

Consulting Framework

  • Customer: Operations manager and frontline staff
  • Problem: Repeat policy/process questions consume team capacity
  • Solution: File-grounded agent with clear escalation rules

Challenge 1: Upload Knowledge Files (10 mins)

Use the files in the assets folder for this lab:

  • sop-playbook.md
  • pricing-and-discounts.md
  • service-policies.md

In Copilot Studio, upload these files as your agent knowledge sources.

Challenge 2: Configure Instructions (10 mins)

Set your instructions so the agent:

  • Answers only from uploaded documents
  • Cites which document informed the answer
  • States "I don't find that in current documents" when needed
  • Escalates approvals and exceptions to a human lead

Challenge 3: Validate Team Scenarios (10 mins)

Test with these scenarios:

  • "Can I approve a 15% discount for a returning customer?"
  • "What is the standard onboarding process for a new service account?"
  • "How should we handle a refund request after 45 days?"

✅ Complete When

  • Answers are grounded in uploaded files
  • Agent declines unsupported policy interpretations
  • Escalation language is clear and consistent

Deliverable

Create a short demo transcript showing one policy answer, one escalation, and one "not in docs" response.
