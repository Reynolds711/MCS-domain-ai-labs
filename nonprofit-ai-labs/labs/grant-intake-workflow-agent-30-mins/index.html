Grant Intake Workflow Agent (30 mins)

🏗️ Build a Grant Intake Workflow Agent

⏱️Duration: 30 minutes
🧭Scenario: Development Operations
📂Data: Funder Criteria + Program Priorities

Scenario

Development teams lose time qualifying low-fit grant opportunities. Build an agent that asks the right questions, validates eligibility, and outputs a go/no-go recommendation.

Challenge 1: Build Intake Flow (10 mins)

  • Collect required fields: funder, amount range, deadline, program fit.
  • Ask follow-up questions only when criteria are missing.
  • Capture uncertainty for incomplete opportunities.

Challenge 2: Add Qualification Rules (10 mins)

  • Score opportunity against mission/program priorities.
  • Flag disqualifiers (eligibility mismatch, timing risk).
  • Route medium-confidence opportunities for human review.

Challenge 3: Generate Decision Brief (10 mins)

  • Output go/no-go recommendation with rationale.
  • List missing evidence and next actions.
  • Produce a one-page brief for leadership review.

✅ Complete When

  • Agent collects complete intake details in multi-turn chat
  • Qualification output is consistent across 3 sample grants
  • Decision brief supports faster team alignment

Deliverable

Submit 3 generated go/no-go briefs and note one workflow improvement based on testing.
